# Cara Penggunaan

## Private chat

```text
/start
/help
/kbbi kucing
/kbbi rumah sakit
/ping
/stats
```

## Group atau guest mode

```text
@KBBI2bot rumah sakit
/kbbi@KBBI2bot rumah sakit
```

Input maksimal 100 karakter dan 3 kata. Pencocokan mention tidak membedakan huruf besar dan kecil.

Hasil menampilkan definisi utama secara langsung, sedangkan contoh, peribahasa, dan sublema ditempatkan dalam bagian quote yang dapat dibuka.
