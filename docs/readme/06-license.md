# Keputusan Lisensi

Status: Dipilih — `AGPL-3.0-or-later`

## Rekomendasi

Proyek menggunakan **GNU AGPLv3-or-later** untuk kode bot dan dokumentasi proyek.

GNU GPLv3 cocok jika fokusnya adalah kebebasan saat kode didistribusikan. Namun GPL biasa tidak mewajibkan operator yang hanya menjalankan versi modifikasi di server untuk menerbitkan source code versi server tersebut. AGPL menambahkan kewajiban untuk software yang digunakan melalui jaringan.

## Batas lisensi

Lisensi ini hanya berlaku untuk kode bot dan dokumentasi proyek. Data definisi yang diambil dari KBBI Online memiliki sumber, hak cipta, dan ketentuan terpisah. Repository tidak akan membundel corpus KBBI sebagai data milik proyek.

Teks lisensi lengkap tersedia di [LICENSE](../../LICENSE). Pada implementasi nanti, `/help` perlu menyediakan tautan source code proyek agar kewajiban pemberian source untuk penggunaan melalui jaringan dapat dipenuhi.

URL repository publik belum ditetapkan. Setelah repository tersedia, URL tersebut harus dimasukkan ke konfigurasi atau formatter `/help`.
